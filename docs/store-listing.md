# 스토어 등록 정보 초안

## 앱 이름 (30자 이내)

`스킨 알리미 - 상점 스킨 알림`

> Riot 의 팬 창작물 정책(Legal Jibber Jabber)은 프로젝트 이름에 Riot 의 상표를 넣지 말라고 안내합니다.
> 앱 이름에는 "VALORANT/발로란트"를 넣지 말고 설명에서만 언급하는 것이 안전합니다.
> 앱 내 표시 이름을 바꾸려면 `app.json` 의 `expo.name` 을 수정하세요.

## 짧은 설명 (80자 이내)

`VALORANT 계정 최대 4개의 일일 상점을 확인하고, 원하는 스킨이 뜨면 바로 알려드려요.`

## 자세한 설명

매일 아침 상점을 일일이 켜서 확인하기 귀찮으셨나요?
스킨 알리미는 등록한 계정(최대 4개)의 VALORANT 일일 상점과 야시장을 확인하고, 위시리스트에 담아 둔 스킨이 등장하면 휴대폰 알림으로 알려줍니다.

주요 기능
• 계정 최대 4개 연동 — Riot 공식 로그인 페이지에서 로그인, 비밀번호는 저장하지 않음
• 위시리스트 — 스킨 이름으로 정확히 등록하거나 "리버"처럼 키워드로 시리즈 전체 등록
• 오늘의 상점 — 스킨 이미지, 가격, 등급, 야시장 할인율, 갱신 카운트다운
• 자동 확인 — 상점이 갱신되는 시각 이후 백그라운드에서 확인, 앱을 열 때도 즉시 확인
• 알림 — 휴대폰 알림, 선택적으로 Discord 웹훅 전송
• 모든 데이터는 기기 안에만 저장되며 별도 서버가 없습니다

주의
• 이 앱은 Riot Games 와 무관한 비공식 앱입니다. VALORANT 는 Riot Games, Inc. 의 상표입니다.
• Riot 이 공식 제공하지 않는 API 를 사용하므로 Riot 의 정책 변경에 따라 동작이 중단될 수 있습니다.
• 백그라운드 확인 시점은 운영체제가 결정하며, 배터리 절전 설정에 따라 지연될 수 있습니다.

## 데이터 보안(Play) 섹션 참고 답변

- 개발자 서버로 전송되는 데이터: 없음
- 앱이 기기에 저장하는 데이터: 로그인 세션 쿠키(암호화 저장), 계정 닉네임, 위시리스트
- 데이터 암호화 전송: 예 (HTTPS)
- 데이터 삭제 요청 방법: 앱 내 계정 삭제 / 앱 삭제

> Play 의 "데이터 보안" 정의상 "수집"은 기기 밖으로 전송되는 데이터를 뜻합니다. 로그인 세션은 Riot 서비스에만 전송되고 개발자는 받지 않으므로 대부분 "수집 안 함"으로 답할 수 있지만, 심사팀이 "인증 정보"를 수집 항목으로 요구하면 "앱 기능 - 계정 관리" 목적으로 신고하세요.
