# 개인정보처리방침 — 발로 스킨 알리미

최종 수정일: 2026-09-10

발로 스킨 알리미(이하 "앱")는 사용자가 등록한 VALORANT 계정의 일일 상점을 확인해 원하는 스킨이 등장하면 알림을 보내는 개인용 도구입니다. 앱은 별도의 서버를 운영하지 않으며, 모든 처리는 사용자의 기기 안에서 이루어집니다.

## 1. 수집·저장하는 정보

| 항목 | 저장 위치 | 용도 |
|---|---|---|
| Riot 로그인 세션 쿠키(`ssid`) | 기기의 보안 저장소(Android Keystore / iOS Keychain) | 상점 조회를 위한 재인증 |
| Riot 계정 식별자(PUUID), 게임 닉네임·태그, 지역 | 기기 내부 저장소 | 계정 구분 및 화면 표시 |
| 위시리스트, 알림 기록, 상점 조회 결과, 앱 설정 | 기기 내부 저장소 | 앱 기능 제공 |
| Discord 웹훅 URL (사용자가 직접 입력한 경우에만) | 기기 내부 저장소 | 사용자가 지정한 Discord 채널로 알림 전송 |

- 앱은 Riot 계정의 **아이디와 비밀번호를 저장하지 않습니다.** 로그인은 Riot 의 공식 로그인 페이지(auth.riotgames.com)에서 이루어집니다.
- 앱은 광고 식별자, 위치 정보, 연락처, 사용 분석(analytics) 데이터를 수집하지 않습니다.

## 2. 정보가 전송되는 곳

앱은 기능 제공을 위해 다음 서비스와 통신합니다. 개발자가 운영하는 서버로는 어떠한 정보도 전송되지 않습니다.

- **Riot Games** (auth.riotgames.com, entitlements.auth.riotgames.com, pd.*.a.pvp.net 등): 로그인 세션 갱신 및 상점 조회
- **valorant-api.com**: 스킨 이름·이미지·등급 등 공개 카탈로그 조회 (계정 정보는 전송되지 않음)
- **Discord** (사용자가 웹훅을 설정한 경우에만): 알림 메시지 전송

## 3. 보관 기간 및 삭제

- 모든 정보는 사용자가 앱에서 계정을 삭제하거나 앱을 삭제할 때까지 기기에만 보관됩니다.
- "계정" 화면에서 계정을 삭제하면 해당 계정의 세션 쿠키와 관련 데이터가 즉시 삭제됩니다.
- 앱을 삭제하면 모든 데이터가 함께 삭제됩니다.

## 4. 제3자 제공

개발자는 사용자의 정보를 수집하지 않으므로 제3자에게 제공하지 않습니다.

## 5. 아동의 개인정보
