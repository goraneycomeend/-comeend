이 화면은

메이퇀(美团) 배달 앱의 주문 확인 화면이에요. 결제 직전 단계입니다.

화면 글자

  • 收货地址 (shōuhuò dìzhǐ) → 배달 받을 주소
  • 餐具份数 (cānjù fènshù) → 수저·포크 개수
  • 无需餐具 (wúxū cānjù) → 수저 필요 없음
  • 配送费 ¥3 (pèisòng fèi) → 배달비 3위안
  • 备注 (bèizhù) → 요청사항
  • 提交订单 (tíjiāo dìngdān) → 주문 제출

지금 할 일

  1. 위쪽 收货地址를 눌러 호텔 주소와 방 번호(门牌号)를 확인하세요.
  2. 필요하면 备注에 "不要辣"(안 맵게)를 적으세요.
  3. 오른쪽 아래 提交订单을 누르면 결제 화면으로 넘어가요.
