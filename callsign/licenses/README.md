# 라이선스 사본

앱과 함께 배포하는 것들의 라이선스 원문을 모아 두는 폴더입니다.

## SUPERTONIC-3-MODEL-LICENSE.txt

음성 합성 모델 **Supertonic 3**(Supertone)의 가중치에 붙은 라이선스 원문입니다. BigScience Open RAIL-M (2022-08-18).

- 받은 곳: `https://huggingface.co/supertone-oss-archive/supertonic-3` 의 `LICENSE`,
  리비전 `aafc6e32416a594460b32413efc49d7fe4ce6d46` (`scripts/fetch-models.mjs` 가 모델 파일을 받는 리비전과 같습니다)
- 원문 그대로이고 고치지 않았습니다. 15,007바이트,
  sha256 `0d944a9110fed9a9602d60e0423a272903e7bd21ab060490774efc77c2275e9f`
- 적용 대상: 앱이 쓰는 모델 파일 전부. 공식 원본(fp32)이든 그것을 줄인 것(int8)이든 같은 모델에서 나온 것이라 이 라이선스를 따릅니다.

이 라이선스는 모델이나 그 파생물을 다른 사람에게 건넬 때 **라이선스 사본을 함께 주고**(4.b),
**부록 A 의 사용 제한이 적용된다는 것을 알리라고**(4.a) 요구합니다.
그래서 모델 파일이 들어가는 배포물(웹 빌드, PC 앱, 모바일 앱)에는 이 파일을 반드시 함께 넣어야 합니다.
사용 제한 안내는 앱의 정보 화면(모델 이름·라이선스 이름·사용 수칙)이 맡습니다.

모델을 돌리는 코드(ONNX Runtime 등)와 앱 자체의 라이선스는 이 파일과 별개입니다.
